## 🔍 Project Overview

The Criminal Investigation Tracker is a software solution designed to **analyze case data**, **identify suspects**, and **automatically generate investigation summaries** and **charge sheets**.

Used by officers within Kerala Police, it connects to the department's internal database, processes live case files, and applies logic-driven filtering and machine learning-based heuristics to prioritize potential suspects.

What previously took hours or days is now completed in under 15 minutes.

---

## 💡 Key Features

- 🚨 **Live integration with Kerala Police database servers**
- 🤖 **Automatic suspect prediction** based on historical crime patterns
- 📄 **Instant charge sheet generation** with full suspect profile and evidence references
- 📂 **Track multiple investigations** from one central dashboard
- 🧠 **Pattern-based filtering**: weapon used, location, prior cases, gang affiliations, and more
- 📊 **Progress monitoring** for ongoing cases (solved vs pending)
- 🔐 **Role-based access** for officers, investigators, and administrators
